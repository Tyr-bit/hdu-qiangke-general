# 杭电抢课脚本（通用版）

用于杭州电子科技大学自主选课（newjw.hdu.edu.cn）的通用抢课脚本：交互输入学号密码，可批量选多门课，每门课可选多个教学班，高频轮询直到抢到为止。

## 运行方法

需要 Python 3.8+ 和 requests 库：

```bash
pip install requests
python hdu_qiangke_general.py --interval 2 --max 0
```

- `--interval 2`：每 2 秒抢一次（可改）
- `--max 0`：无限轮询，抢到自动停止；也可填具体轮数（如 `--max 100`）
- 加 `--once` 只跑一轮，用于测试账号和链路

## 使用方法

启动后按提示依次输入：

1. 学号
2. 密码（不回显，属正常）
3. 课程号（如 `XX000000`）
4. 教师关键词（可选，如 `张老师`；直接回车则不筛选）
5. 教学班序号（输入 `1,2,3` 多选；直接回车 = 全选）
6. 是否继续添加课程（`y` 加下一门，`n` 开始抢课）

抢到后脚本自动停止；断网会自动重登。日志保存在同目录 `logs/` 下。

> 说明：脚本仅供个人选课使用，抢到与否取决于教务系统是否有名额。
